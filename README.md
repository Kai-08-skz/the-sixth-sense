# 🛡️ The Sixth Sense

**The Sixth Sense** is a multi-layered cyber-defense console engineered to detect and neutralize AI-generated voice deepfakes. 

While the project was officially submitted under a required **6-person team banner** for the **Smart India Hackathon (SIH) Internal Rounds**, **the entire technical architecture, codebase (`app.py`), environment pipeline, and functional prototype were executed and built independently by a single developer (Kai-08-skz).**
